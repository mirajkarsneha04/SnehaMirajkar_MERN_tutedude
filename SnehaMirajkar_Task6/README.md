# Task: Split Layout Login Page

A modern, responsive login page featuring a split-screen design. One section highlights an engaging visual illustration, while the other provides a clean form interface for user authentication.

## Project Description
This project focuses on creating an intuitive authentication page that enhances user engagement during the login process. It utilizes a split-layout structure to balance visual appeal with functional form inputs.

## Features
- Split Layout Architecture: Separate divisions for visual media and form elements.
- User Authentication Inputs: Structured input fields for user email and password.
- Interactive UI Components: Custom-styled action buttons and styled form containers.
- Clean Styling: Organized CSS structure using standard web layout techniques.

## File Structure
- `index.html` - HTML5 document structure containing the form elements and visual container.
- `style.css` - Custom styles covering page layout, input field formatting, and visual components.
- `README.md` - Documentation for project overview and details.
